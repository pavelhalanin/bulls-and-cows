### Описание алгоритма evaluateGuess

Функция evaluateGuess - возращает объект с количеством коров и быков.

**Бык** - это разряд числа загадываемого числа совпадает с предполагаемым.

> Например, 123 и 426. Число 2 совпадает разрядами, поэтому 1 бык.
>
> Например 123 и 423. Число 2 и 3 совпадают разрядами, поэтому 2 быка.
>
> Например 123 и 123. Числа 1, 2, 3 совпадают разрядами, поэтому 3 быка.
>
> Например 123 и 456. Нет совпадений по разряду, поэтому 0 быков.

**Корова** - это наличие числа, но не совпадение по разряду.

> Например 123 и 312. Разряды не совпадают но числа 3, 1 и 2 есть, поэтому 3 коровы.
>
> Например 123 и 345. Число 3 есть и разряд не совпадает, поэтому 1 корова.
>
> Например 123 и 324. Число 3 есть и разряд не совпадает, но у числа 2 разряд совпадает, поэтому 1 бык и 1 корова.

### Описание алгоритма countPossibleSecrets

Функция countPossibleSecrets - возращает количество уникальных перестановок.

По теории вероятности перестановки считаются по формуле:

P = b! / (l - b)!,

где b - система счисления, а l - длина числа.

Для факториала граница:

- n = 1
- n = 0
- n < 0

```txt
4! = 4 * 3 * 2 * 1 = 24 = 4 * 3!
3! = 3 * 2 * 1 = 6 = 4! / 4
2! = 2 * 1 = 3! / 3
1! = 1 = 2! / 2
0! = 1! / 1 = 1 / 1 = 1
-1! = 0! / 0 = 1 / 0 - не определено
```

Для подсчета функции использован аналог функции вычисляемый по формуле `base * countPossibleSecrets(length - 1, base - 1)` указав границы:

- l = 0 - функция вернет 1
- l > b - функция вернет 0 как невозможному случаю
- l < 0 - функция вернет 0 как невозможному случаю
- b < 0 - функция вернет 0 как невозможному случаю

## Сложность

Вычислительная сложность generateSecret(length, base) - O(n^2) - это квадратичная сложность, так как используются циклы второго порядка: сначало while перебирая length, затем filter перебирая по base.

Вычислительная сложность evaluateGuess(secret, guess) - O(n^2) - это квадратичная сложность, так как используются циклы второго порядка: сначала перебор по reduce массива букв secret, затем перебор по indexOf массива букв по guess.

Вычислительная сложность isValidGuess(guess, length, base) - O(2n) - это линейная сложность, так как используются циклы первого порядка: сначала перебор .split() по guess, затем перебор .every() по guess.

Вычислительная сложность countPossibleSecrets (length, base) - O(n) - это линейная сложность, так как используется цикличный вызов стека функций до граничных значений.
